 Farm Site Management System
Introduction

The Farm Site Management System is a web-based application developed to help farmers manage and sell farm products online. The system allows farmers to add crop details, customers to view products, and place orders through the website easily.

Objective
To provide an online platform for farmers to sell crops.
To simplify crop and order management.
To maintain farmer and customer records efficiently.

Working Process
Farmer registers into the system.
Farmer adds crop details.
Crop details are stored in MongoDB database.
Available crops are displayed on the website.
Customers view products.
Customers place orders.
Order details are stored in database.
Crop quantity gets updated automatically.
Advantages
Easy to use
Faster product management
Reduces manual work
Online ordering facility
Efficient data storage using MongoDB
Conclusion

The Farm Site Management System provides an efficient platform for farmers and customers. It simplifies crop management, online product display, and customer ordering using modern web technologies.
